## 二、已确认的现象（一条一句 + 证据位）

### 2.1 Doly（**已跑通**）

1. **硬件**：ESP32-P4 **rev v1.3**，USB-Serial/JTAG，COM6。证据：`esptool chip_id`。
2. **P4 没有内置 WiFi**：靠 SDIO 外挂 C6，需 **LDO 通道 4 给 3.3V**（MIPI 另需通道 3 给 2.5V）。证据：Doly `dooirobot.cc` 注释 + 实测连上。
3. **SDIO 真实引脚**：CLK **47** / CMD **48** / D0 **46** / D1 **45** / D2 **44** / D3 **43** / RESET **42**。
   ⚠️ ESP-IDF 默认那组（18/19/14/15/16/17/54）**会撞 LCD(14/15/16) 和电机(17/18)**，必须覆盖。
4. **双 240×240 GC9A01 圆屏**，共用背光 GPIO16；第一阶段只驱动 LCD1（SPI2）。
5. **屏需要 `mirror_x=true`**。证据：Doly `display_hal.c:166` `esp_lcd_panel_mirror(panel, true, false)`。
6. **32MB flash**，分区含 `model`(4M) / `assets`(8M) / `behavior`(2M)。**必须开 32 位地址**（`CONFIG_SPI_FLASH_32BIT_ADDR_ENABLE`），否则 16MB 之后的分区读不到。
7. **音频是两颗芯片**：ES8311（输出，PA=40）+ ES7243E（输入，地址要 `<<1`）。参考通道在 slot0，读完要交换相邻两个 int16。
8. **NVS 里的 `wifi/ota_url` 会盖掉编译值**。实测：固件里已无 `api.tenclass.net` 字样，设备仍连它。证据：dump NVS 后在分区里搜到 `tenclass`。
9. **`esp_hosted` 2.0.17 → 2.11.7 修掉了崩溃循环**（`assert netif_add … netif already added`）。
   该组件带 `rules: target in [esp32h2, esp32p4]` ⇒ **S3 的瓦力/月球车/MOSS 完全不受影响**。

### 2.2 自建后台（**已跑通**）

### 4.4 固件里现有的"命令词汇"（后台照这个发）

```json
{"type":"command","payload":{"actions":[
  {"type":"gpio","pin":17,"level":1,"duration":1200},
  {"type":"pwm","pin":32,"freq":50,"pulse_us":2000,"duration":400},
  {"type":"ws2812","pin":5,"count":1,"rgb":[64,0,0],"duration":3000},
  {"type":"camera","op":"capture"},
  {"type":"delay","duration":300}
]}}
```

| 字段 | 语义 |
|---|---|
| `gpio.pin/level` | 引脚 + 电平；`duration` 到点**自动回落低电平** |
| `pwm.pin/freq` | 引脚 + 频率；脉宽模式给 `pulse_us`（舵机 500~2500），占空比模式给 `duty`(0~100) |
| `pwm.duration` | 到点占空比归零 |
| `ws2812.pin/count` | 数据引脚 + 灯珠数量；`rgb` 三色 0~255（也可写 `r`/`g`/`b`），**不给颜色 = 关灯** |
| `ws2812.duration` | 到点自动关灯（所有像素清零） |
| `camera.op` | `capture`（默认，抓一帧）/ `explain`（抓帧并上传后台视觉接口）。**不需要 LLM 就能触发** |
| 自动处理 | 首次使用自动配成输出；LEDC 通道/定时器自动分配（最多 8 路 PWM、4 种频率）；WS2812 按 `(pin,count)` 缓存 RMT 句柄（最多 4 条带） |

**串口上对应的判据**：`GPIO 17 -> 1 (hold 1200 ms)` / `[PWM] pin=32 freq=50 pulse_us=2000 bits=14 duty=…` / `[WS2812] pin=5 count=1 rgb=(64,0,0)` / `[CAMERA] 抓帧成功` + `mmap_buffers_[..].length = …`

> ⚠️ **`ws2812` 是 2026-10-27 才加的**，只有重编过的板子才认。已在 **月球车（GPIO5，GRB 正确，实测点亮）** 验证；
> 其余板子（瓦力 / 月球车旧固件 / MOSS）上的旧固件**没有**这个动作，会打 `未知动作类型: ws2812`。
> WS2812 必须走 RMT 数据流，`gpio`/`pwm` 对它无效（打高电平灯纹丝不动）。
>
> ⚠️ **`camera` 是 2026-10-31 才加的**，同样只有重编过的板子才认。已在 **MOSS（OV2640，抓帧 614400 B / 640×480）** 验证。

### 4.5 本场踩过的环境坑（都真的踩了）

- **本机 `pwsh` 是 Windows PowerShell 5.1**：`Get-Content` 读 UTF-8 中文乱码、行号会错 ⇒ **看文件用 read 工具**。
- **PowerShell 命令里带中文引号/全角符号会解析失败**（本场踩了两次）⇒ 命令里一律用 ASCII，中文放到脚本文件里。
- **手动拨 DTR/RTS 复位会打出假的 `Guru Meditation Error`**（`Instruction access fault`）⇒ 别拿它当固件 bug；稳定观测时**不要碰 DTR/RTS**。
- **后台启动要 40~50 秒**（SenseVoice 模型加载）⇒ 端口没起不代表失败。
- **`config.yaml` 的 `ip: 0.0.0.0`**，服务自动探测本机 IP ⇒ 日志里报的地址就是当前 IP，会随 IP 变化。
- **工作区没有 git**，无回滚点 ⇒ 改配置前先 `Copy-Item` 备份（本次已备 `config.yaml.bak_20261026`）。
- **本机内存只有 7.9 GB（可用 ~1.7 GB），并行编译会 OOM**：报 `cc1plus.exe: out of memory allocating 65536 bytes`。
  解法：`$env:NINJAFLAGS = "-j1"` 再 `idf.py build`（`idf.py -j 1` 在这个 IDF 版本**不支持**，会报 `No such option: -j`）。
- **读整片 flash 用 921600 会 `Write timeout`**（坏在 ~24%），要降到 **460800** 才稳。
