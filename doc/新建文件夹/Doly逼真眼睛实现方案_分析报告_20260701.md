**日期**: 2026-07-01  
**项目**: 小智多机器人调度系统（xiaozhi-esp32 改造）  
**板型**: waveshare-s3-dualeye-lcd-1.28（双目屏，Doly）  
**分析范围**:

- `esp32-firmware/main/display/emote_display.cc` — 原 xiaozhi-esp32 的 GFX/EAF 表情系统

## 1. 核心发现

### 1.1 当前纯色椭圆的来源 ✔️ 已验证

当前 `ui_emoji_dualeye.cc`（以及 Doly 源码中的 `ui_emoji.c`）的实现在设计目标上就是 **纯色椭圆**，并非不完整。

核心证据：

**文件**: `ui_emoji.c` 行 11
```c
#define EMOJI_COLOR  lv_color_hex(0x00E5FF) // Nomi 科技青
```

创建眼睛对象的代码（行 237-241）：
```c
eye->eye_obj = lv_obj_create(cont);
lv_obj_set_size(eye->eye_obj, EYE_DEFAULT_W, EYE_DEFAULT_H);
lv_obj_set_style_radius(eye->eye_obj, EYE_RADIUS_MAX, 0);  // 100 = 胶囊形
lv_obj_set_style_bg_color(eye->eye_obj, EMOJI_COLOR, 0);   // 纯色填充
lv_obj_set_style_bg_opa(eye->eye_obj, LV_OPA_COVER, 0);    // 完全不透明
```

**结论**: 这就是一个 `lv_obj` 圆角矩形（胶囊形状），通过 5 个维度的动画（宽/高/旋转/XY偏移）来模拟表情变化。没有瞳孔、虹膜、高光等细节。

### 1.2 Doly 源码分析文档的确认

**文件**: `doc/Doly源码分析_可复用模式_20260628.md` 行 258

> "Doly 的表情系统是**纯软件渲染**（LVGL 动画）而非图片/EAF 文件"

该分析文档（3.2 节）完整审查了 `ui_emoji.c`，确认其渲染方式就是 `lv_obj` 胶囊形动画。

### 1.3 两份代码的关系

| 代码 | 目录 | 渲染方式 | 视觉效果 |
|------|------|---------|---------|
| `ui_emoji.c` | `dooirobot/` | LVGL `lv_obj` 纯色椭圆 + 动画 | 科技青椭圆 |
| `ui_emoji_dualeye.cc` | `esp32-firmware/boards/.../` | 同上（移植版） | 同上 |
| `EmoteDisplay` (GFX/EAF) | `esp32-firmware/main/display/` | `esp_emote_gfx` + `.eaf` 动画文件 | 逼真眼睛动画 |

**重要**: Doly 成品可能使用的是第二套系统（EmoteDisplay + EAF），而这套系统的渲染代码**不在当前 dooirobot 源码中**。

## 2. Doly 成品可能使用的 3 种实现方案

### 方案 A：GFX/EAF 动画渲染（最可能）✔️ 已验证

**技术原理**: 使用 `espressif2022/esp_emote_gfx` 组件，播放预渲染的 `.eaf` 格式动画文件。EAF 是将 GIF 动画转换而来的帧动画格式，包含完整的像素数据。

**文件**: `esp32-firmware/managed_components/espressif2022__esp_emote_gfx/README.md` 行 220

```c
// 创建动画对象
gfx_obj_t *anim_obj = gfx_anim_create(emote_handle);

// 加载动画数据（.eaf 文件）
gfx_anim_set_src(anim_obj, anim_data, anim_size);
gfx_obj_set_size(anim_obj, 200, 150);

// 播放控制
gfx_anim_set_segment(anim_obj, start_frame, end_frame, fps, loop);
gfx_anim_start(anim_obj);
```

**EAF 文件列表**（存在于 `esp_emote_gfx/emoji_large/`）:
```
angry.eaf, Happy.eaf, Sad.eaf, cry.eaf, confused.eaf,
shocked.eaf, winking.eaf, sleep.eaf, listen.eaf, neutral.eaf
```

**emote.json 映射示例** (`esp32-firmware/main/boards/echoear/emote.json`):
```json
[
    {"emote": "happy",    "src": "Happy.eaf",    "loop": true,  "fps": 20},
    {"emote": "sad",      "src": "Sad.eaf",      "loop": true,  "fps": 20},
    {"emote": "angry",    "src": "angry.eaf",    "loop": true,  "fps": 20},
    ...
]
```

**`EmoteDisplay::SetEmotion` 实现**（`emote_display.cc` 行 ~350）:
```cpp
void EmoteDisplay::SetEmotion(const char* emotion) {
    // 通过 emote.json 查找对应的 EAF 文件
    // 加载 EAF 数据 → gfx_anim_set_src
    // 设置动画片段 → gfx_anim_set_segment
    // 播放 → gfx_anim_start
}
```

**优点**:
- ✅ 可以呈现**精美的、有瞳孔/虹膜/高光的逼真眼睛**
- ✅ EAF 通过 GIF 在线工具创建，美术资源丰富
- ✅ 有 30fps 硬件加速渲染，性能好
- ✅ 已在其他 xiaozhi-esp32 板型上验证可行

**缺点**:
- ❌ 需要预制作的 GIF/EAF 资源（美术工作）
- ❌ 动画是固定帧序列，无法动态调整（不像 LVGL 动画可实时改变参数）
- ❌ EAF 文件占用 flash 空间（每个数百 KB）

---

### 方案 B：LVGL 多层 `lv_obj` 组合（推荐新手）

**技术原理**: 用多个 LVGL 基础对象叠加组成眼睛——白色胶囊背景 + 黑色圆形瞳孔 + 白色高光点 + 睫毛。

**伪代码示意**:
```c
static void create_realistic_eye(lv_obj_t *parent, eye_widgets_t *eye, int x_offset) {
    // 1. 眼睛容器（白色胶囊）
    eye->container = lv_obj_create(parent);
    lv_obj_set_size(eye->container, 60, 100);
    lv_obj_set_style_radius(eye->container, LV_RADIUS_CIRCLE, 0);
    lv_obj_set_style_bg_color(eye->container, lv_color_hex(0xFFFFFF), 0); // 白色眼白
    lv_obj_set_style_bg_opa(eye->container, LV_OPA_COVER, 0);
    lv_obj_set_style_border_width(eye->container, 1, 0);
    lv_obj_set_style_border_color(eye->container, lv_color_hex(0x888888), 0);

    // 2. 瞳孔（黑色圆形）
    eye->pupil = lv_obj_create(eye->container);
    lv_obj_set_size(eye->pupil, 20, 20);
    lv_obj_set_style_radius(eye->pupil, LV_RADIUS_CIRCLE, 0);
    lv_obj_set_style_bg_color(eye->pupil, lv_color_hex(0x000000), 0);
    lv_obj_set_style_border_width(eye->pupil, 0, 0);
    lv_obj_align(eye->pupil, LV_ALIGN_CENTER, 0, 0);

    // 3. 高光（白色小圆点）
    eye->highlight = lv_obj_create(eye->pupil);
    lv_obj_set_size(eye->highlight, 6, 6);
    lv_obj_set_style_radius(eye->highlight, LV_RADIUS_CIRCLE, 0);
    lv_obj_set_style_bg_color(eye->highlight, lv_color_hex(0xFFFFFF), 0);
    lv_obj_set_style_border_width(eye->highlight, 0, 0);
    lv_obj_align(eye->highlight, LV_ALIGN_TOP_LEFT, 3, 3);
}
```

表情变化时，对不同图层做不同动画：
- `container` → 整体大小/旋转（同现有逻辑）
- `pupil` → 平移（模拟视线方向）+ 缩放（模拟瞳孔变化）
- `highlight` → 跟随瞳孔移动

**优点**:
- ✅ 纯 LVGL，无外部依赖
- ✅ 可动态控制各部件（视线、瞳孔大小、眨眼）
- ✅ 表情切换可继续使用 `lv_anim_start` + overshoot 曲线

**缺点**:
- ❌ 需要大量的动画参数调整
- ❌ 无法实现渐变色虹膜等复杂效果
- ❌ 子对象的动画同步需要额外处理

---

### 方案 C：LVGL Canvas 逐像素绘制（最逼真）

**技术原理**: 使用 `lv_canvas` 或 LVGL v9 的 `lv_draw_image` / `lv_draw_arc` / `lv_draw_rect` 等绘图 API 在内存缓冲区中绘制眼睛，然后刷新到显示。

```c
// 创建 canvas 对象
lv_obj_t *canvas = lv_canvas_create(parent);
lv_canvas_set_buffer(canvas, buf, 120, 120, LV_IMG_CF_TRUE_COLOR);

// 在 canvas 上绘制眼睛
lv_canvas_fill_bg(canvas, lv_color_hex(0x000000), LV_OPA_COVER); // 背景透明
lv_canvas_draw_arc(canvas, 60, 60, 40, 0, 3600, &arc_dsc);       // 虹膜弧
lv_canvas_draw_circle(canvas, 60, 60, 15, &circle_dsc);           // 瞳孔
lv_canvas_set_px(canvas, 50, 45, lv_color_hex(0xFFFFFF));         // 高光像素
```

**优点**:
- ✅ **最逼真**：可以实现渐变色虹膜、放射状纹理、高光反射
- ✅ 完全可控：每帧可以重绘任意形状
- ✅ 可集成数学函数生成自然的眼睛纹理

**缺点**:
- ❌ 需要大块内存缓冲区 (120×120×2 = 28.8KB per eye)
- ❌ CPU 占用高，逐像素绘制需要优化
- ❌ 动画逻辑复杂（需要自己写帧循环）
- ❌ LVGL canvas 和 `lv_anim` 的集成需要额外工作

---

### 方案对比

| 维度 | A: EAF 动画 | B: LVGL 多层对象 | C: Canvas 逐像素 |
|------|------------|-----------------|-----------------|
| 逼真度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 实现难度 | ⭐⭐（资源已有） | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 内存开销 | 低（硬件解码） | 极低 | 较高（28KB/眼） |

| 复用现有动画引擎 | ❌ 需切换渲染系统 | ✅ 可保留 | ❌ 需重写 |
| 资源需求 | EAF 文件（需要制作） | 无 | 无 |

### 4.4 Phase 3: Canvas 逐像素绘制（终极方案）

**步骤 1**: 在初始化时创建 Canvas

```c
#define EYE_CANVAS_W 120
#define EYE_CANVAS_H 120

static lv_color_t canvas_buf[EYE_CANVAS_W * EYE_CANVAS_H];

void init_eye_canvas(lv_obj_t *parent, int x_offset) {
    lv_obj_t *canvas = lv_canvas_create(parent);
    lv_canvas_set_buffer(canvas, canvas_buf, EYE_CANVAS_W, EYE_CANVAS_H, LV_IMG_CF_TRUE_COLOR);
    lv_obj_align(canvas, LV_ALIGN_CENTER, x_offset, 0);
}
```

**步骤 2**: 实现眼睛绘制函数

```c
typedef struct {
    float pupil_x, pupil_y;     // 瞳孔位置 (-1.0 ~ 1.0)
    float pupil_size;           // 瞳孔大小 (0.2 ~ 1.0)
    float iris_hue;             // 虹膜色调
    float eye_openness;         // 睁眼程度 (0.0 ~ 1.0)
    float eye_angle;            // 旋转角度
} eye_render_params_t;

void render_eye_canvas(lv_obj_t *canvas, const eye_render_params_t *params) {
    lv_canvas_fill_bg(canvas, lv_color_hex(0x000000), LV_OPA_TRANSP);

    lv_draw_rect_dsc_t sclera_dsc = {0};  // 眼白
    lv_draw_rect_dsc_init(&sclera_dsc);
    sclera_dsc.bg_color = lv_color_hex(0xFFFFFF);
    sclera_dsc.radius = LV_RADIUS_CIRCLE;
    // ... 绘制眼白椭圆

    lv_draw_arc_dsc_t iris_dsc = {0};     // 虹膜（渐变色）
    lv_draw_arc_dsc_init(&iris_dsc);
    iris_dsc.color = lv_color_hex(0x00E5FF);
    iris_dsc.width = 8;                   // 环宽
```
