def tts_text_priority_thread(self):
    while not self.conn.stop_event.is_set():
        try:
            message = self.tts_text_queue.get(timeout=1)
            # 过滤旧 sentence_id
            if ContentType.TEXT == message.content_type:
                self.tts_text_buff.append(message.content_detail)
                segment_text = self._get_segment_text()
                if segment_text:
                    # 调用 TTS 服务生成语音 → handle_opus 回调放入音频队列
                    self.to_tts_stream(segment_text, opus_handler=self.handle_opus)
            if message.sentence_type == SentenceType.LAST:
                self._process_remaining_text_stream(opus_handler=self.handle_opus)
                self.tts_audio_queue.put(
                    (message.sentence_type, [], message.content_detail, message.sentence_id)
                )
```

def _audio_play_priority_thread(self):
    while not self.conn.stop_event.is_set():
        try:
            item = self.tts_audio_queue.get(timeout=0.1)
            sentence_type, audio_datas, text, sentence_id = item
            # 发送音频（最终会走 WebSocket）
            future = asyncio.run_coroutine_threadsafe(
                sendAudioMessage(self.conn, sentence_type, audio_datas, text, sentence_id),
                self.conn.loop,
            )
            future.result()
```

async def sendAudioMessage(conn, sentenceType, audios, text, sentence_id=None):
    if sentenceType == SentenceType.FIRST:
        # 新句子开始 → 发送 {"type": "tts", "state": "sentence_start", "text": ...}
        await send_tts_message(conn, "sentence_start", text)
    # 发送 Opus 音频包（走 WebSocket）
    await sendAudio(conn, audios)
    if sentenceType == SentenceType.LAST:
        # 句子结束 → 发送 {"type": "tts", "state": "stop"}
        await send_tts_message(conn, "stop", None)
```

async def send_tts_message(conn, state, text=None):
    message = {"type": "tts", "state": state, "session_id": conn.session_id}
    if text is not None:
        message["text"] = textUtils.check_emoji(text)
    # 发送到 ESP32
    await conn.websocket.send(json.dumps(message))
```

## 说明（调用关系）

```
LLM (response / response_with_functions)
   │  流式产出 (content, tool_calls)
   ▼
chat()                                [connection.py:907]
   │  for response in llm_responses:
   │    self.tts.tts_text_queue.put(TTSMessageDTO)      ← LLM token 入 TTS 文本队列
   ▼
tts_text_priority_thread()            [providers/tts/base.py:368]
   │  self.to_tts_stream() → TTS 服务生成音频
   │  opus_handler → handle_opus → 音频入 tts_audio_queue
   ▼
_audio_play_priority_thread()         [providers/tts/base.py:411]
   │  sendAudioMessage(conn, sentence_type, audios, text)
   ▼
sendAudioMessage()                    [handle/sendAudioHandle.py:20]
   ├── send_tts_message("sentence_start", text)   →  conn.websocket.send(json)
   ├── sendAudio() → _do_send_audio()             →  conn.websocket.send(opus_bytes)
   └── send_tts_message("stop")                   →  conn.websocket.send(json)
```

**下发给 ESP32 的 WebSocket 消息类型**：

| 消息类型 | 方向 | 格式 |
|---|---|---|
| STT 识别文本 | ESP32 ← 服务器 | `{"type":"stt", "text":"...", "session_id":"..."}` |
| TTS 开始 | ESP32 ← 服务器 | `{"type":"tts", "state":"start", "session_id":"..."}` |
| TTS 句子开始+字幕 | ESP32 ← 服务器 | `{"type":"tts", "state":"sentence_start", "text":"...", "session_id":"..."}` |
| TTS 音频流 | ESP32 ← 服务器 | 纯 Opus 二进制包（60ms 帧） |
| TTS 结束 | ESP32 ← 服务器 | `{"type":"tts", "state":"stop", "session_id":"..."}` |

## 结论（修改点建议）

如需**在 LLM 回复下发到 ESP32 之前做拦截/改写/过滤**，推荐以下修改点：

| 优先级 | 修改点 | 文件:行号 | 说明 |
|---|---|---|---|
| **★ 首选** | `chat()` 中 LLM 流式 token 入队列前 | `connection.py:1054-1064` | 拦截 `content` 字符串，改写/过滤后再 `put` 到 `tts_text_queue`；只影响回复内容，不影响对话历史 |
| 备选 1 | `tts_text_priority_thread()` 中处理 `content_detail` 之前 | `providers/tts/base.py:385-389` | 此时文本已被拼合到 `segment_text`，可做整句级处理 |
| 备选 2 | `send_tts_message()` 中 `message["text"]` 赋值前后 | `handle/sendAudioHandle.py:266-272` | 最后的文本修改机会，此时只影响字幕显示，不影响 TTS 生成的音频内容 |

> **注意**：
> - 若需拦截**音频级别**的数据（在发给 ESP32 之前），在 `_do_send_audio()`（`sendAudioHandle.py:245`）拦截 `opus_packet`。
> - 若需修改**TTS 播放结束后的行为**，在 `send_tts_message` 的 `state == "stop"` 分支（`sendAudioHandle.py:275-296`）中插入逻辑。
> - 连接断开清理逻辑在 `close()`（`connection.py:1387`）。
