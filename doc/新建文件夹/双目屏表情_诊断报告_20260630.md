## 2. 发现的问题

### 🔴 问题 1（严重）：lv_display_set_default 导致默认屏指向第二个

**文件**: `display_manager.cc:202`

在初始化第二个屏幕时：
```cpp
lv_display_set_default(display_);  // ← 把默认显示改成了第二个添加的屏幕
```

这意味着 `lv_disp_get_default()`（在 `ui_emoji_init` 中调用）返回的是 **屏幕 #2**，不是屏幕 #1。

而 `lv_disp_get_next(NULL)` 返回的是第一个显示器（在链接列表中的第一个）。

**所以两个显示的传递反了**：
```
ui_emoji_init 传入:
  disp_left  = lv_disp_get_default()      → 屏幕 #2 (第二个初始化的)
  disp_right = lv_disp_get_next(NULL)     → 屏幕 #1 (第一个初始化的)
```

### 🔴 问题 2（严重）：SetupUI 在屏幕上创建原生 UI 元素

**文件**: `display_manager.cc:204`

每个屏幕初始化时调用 `SetupUI()`，它在 LVGL 活动屏幕上创建原生 UI 元素（聊天标签、状态栏等）。紧接着 `ui_emoji_init()` 虽然用 `lv_obj_clean()` 清空了屏幕，但 `Application::Start()` 中的 `SetChatMessage` / `SetStatus` 又会重新创建这些原生 UI 元素。

### 🔴 问题 3（中）：SetChatMessage 会覆盖表情

**文件**: `application.cc:119`

```cpp
display->SetChatMessage("system", "");  // 在每屏上创建覆盖层
display->SetEmotion("microchip_ai");    // e moji_names 中找不到
```

`SetChatMessage` 会在 LVGL 屏幕上创建文字标签，**遮盖**我们的眼睛对象。

### 🔴 问题 4（中）："microchip_ai" 不在表情列表中

`SetEmotion("microchip_ai")` 在 `EMOJI_MAP` 中找不到，无效果。眼睛停留在 `EMOJI_NEUTRAL` 状态。

### 🔴 问题 5（低）：两个表情定时器

`lv_timer_create` 在 `SpiLcdDisplayExtended` 构造函数中执行两次，创建了两个表情刷新定时器。

## 3. "椭圆由小变大"的原因

这是 `render_emoji_logic(EMOJI_NEUTRAL)` 的 `anim_eye_to_state()` 动画在播放：

```
create_eye():                    lv_obj_set_size(eye, 60, 100)    ← 立即生效
ui_emoji_init():
  render_emoji_logic(NEUTRAL):
    anim_eye_to_state(left, {60,100,0,0,0}, 300ms, 0ms)
      → lv_anim_set_values(from=lv_obj_get_width(obj),  to=60)
```

如果 `lv_obj_get_width(obj)` 在动画启动时的返回值不是 60（可能因为某个中间状态），就会产生从"某个值动画到 60"的视觉效果。但更可能的原因是：

1. 屏幕 #1 和 #2 的 `disp_left` / `disp_right` 传递反了
2. 左眼在屏幕 #2 上创建，右眼在屏幕 #1 上创建
3. 屏幕 #1 被 `uv_obj_clean` 清空后抹掉了眼睛
4. 残留的 Q弹动画在"错误"的屏幕上播放

```cpp
// 修改板卡构造函数 — 修复默认屏和屏幕传递
CustomBoard() :
    boot_button_(BOOT_BUTTON_GPIO) {
    InitializeI2c();
    InitializeSpi();
    InitializeLcdDisplay();
    // ★ 第一个 lvgl_port_add_disp() 后，默认屏是屏幕 #1 — 保持这样
    lv_disp_t *disp1 = lv_disp_get_default();    // 保存屏幕 #1

    InitializeLcdDisplay_2();
    // ★ 修复：不要把默认屏改为屏幕 #2
    // 在 display_manager.cc 的第二个构造函数中：
    // lv_display_set_default(display_) 这行会改默认屏 — 需要移除或修复
    lv_disp_t *disp2 = lv_disp_get_next(NULL);   // 获取屏幕 #2（也可能和 disp1 一样）

    // ★ 确保 disp1 != disp2
    if (disp2 == disp1) {
        // lv_disp_get_next(NULL) 返回了同一个显示器
        // 说明 lv_display_set_default 改了链表结构
        // 改用遍历方式
        disp2 = NULL;
        lv_disp_t *d = lv_disp_get_next(NULL);
        while (d) {
            if (d != disp1) { disp2 = d; break; }
            d = lv_disp_get_next(d);
        }
    }

    InitializeButtons();
    GetBacklight()->RestoreBrightness();
    GetBacklight2()->RestoreBrightness();
    DisplayManager::AddDisplay(display_);
    DisplayManager::AddDisplay(display2_);

    // ★ 传入正确的左右屏
    ui_emoji_init(disp1, disp2);
}
```

```cpp
void ui_emoji_set_expression(const char* name) {
    if (name == NULL || s_emoji_mutex == NULL) return;
    
    // ★ 如果不在列表中，默认 "neutral"
    int idx = -1;
    for (int i = 0; i < EMOJI_MAX; i++) {
        if (strcmp(name, emoji_names[i]) == 0) {
            idx = i;
            break;
        }
    }
    if (idx < 0) {
        // 未知表情 → 静默 fallback 到 neutral
        name = "neutral";
        idx = EMOJI_NEUTRAL;
    }
    
    if (xSemaphoreTake(s_emoji_mutex, pdMS_TO_TICKS(100)) == pdTRUE) {
        strncpy(emoji_ctx.current_emoji_name, name, 31);
        emoji_ctx.target_type = (emoji_type_t)idx;
        emoji_ctx.needs_refresh = true;
        xSemaphoreGive(s_emoji_mutex);
        ESP_LOGI("EmojiDualEye", "Set expression: %s", name);
    }
}
```
