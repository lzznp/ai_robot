### 步骤12-13：LLM 调用入口

**文件**: `xiaozhi-server/core/connection.py` 第1067-1148行

```python
def chat(self, query, depth=0):
    """LLM 聊天入口 — 在线程池中执行 (非 async)"""
    # depth=0: 新会话
    current_sentence_id = str(uuid.uuid4().hex)
    self.sentence_id = current_sentence_id
    self.dialogue.put(Message(role="user", content=query))     # → 加入对话历史

    # 在 tts 队列中放入 FIRST 信号
    self.tts.tts_text_queue.put(TTSMessageDTO(
        sentence_id=current_sentence_id,
        sentence_type=SentenceType.FIRST,
        content_type=ContentType.ACTION,
    ))

    # 查询记忆
    memory_str = self.memory.query_memory(query) if self.memory else None

    # 调用 LLM
    if self.intent_type == "function_call":
        llm_responses = self.llm.response_with_functions(      # → 带 function calling
            self.session_id,
            self.dialogue.get_llm_dialogue_with_memory(
                memory_str, self.config.get("voiceprint", {})
            ),
            functions=functions,
        )
    else:
        llm_responses = self.llm.response(                    # → 普通对话
            self.session_id,
            self.dialogue.get_llm_dialogue_with_memory(
                memory_str, self.config.get("voiceprint", {})
            ),
        )
```

| 参数 | 值 | 来源 |

| `session_id` | UUID 字符串 | `connection.py:94` |
| `dialogue` | `[{"role":"system","content":"..."}, {"role":"user","content":"大家好"}]` | 对话管理器 |
| `functions` | 工具列表 (可选) | `func_handler.get_functions()` |

### 步骤17-19：TTS 文本处理与分句

```python
def tts_text_priority_thread(self):
    """TTS 文本消化线程 — 独立线程，后台运行"""
    while not self.conn.stop_event.is_set():
        message = self.tts_text_queue.get(timeout=1)   # ← 从队列取文本

        if self.conn.client_abort:
            continue                                     # 被打断则跳过

        if message.sentence_type == SentenceType.FIRST:
            # 新会话开始，重置状态
            self.current_sentence_id = message.sentence_id
            self.tts_stop_request = False
            self.processed_chars = 0
            self.tts_text_buff = []
            self.tts_audio_first_sentence = True

        elif ContentType.TEXT == message.content_type:
            # ★ 追加文本到缓冲区
            self.tts_text_buff.append(message.content_detail)
            segment_text = self._get_segment_text()     # ← 按标点分句
            if segment_text:
                self.to_tts_stream(segment_text, opus_handler=self.handle_opus)
                      # ↑ 调用子类 TTS 服务合成音频

        if message.sentence_type == SentenceType.LAST:
            self._process_remaining_text_stream(opus_handler=self.handle_opus)
            # 队列中放入 LAST 信号
            self.tts_audio_queue.put((sentence_type.LAST, [], ..., message.sentence_id))
```

def handle_opus(self, opus_data: bytes):
    """Opus 音频处理回调"""

        SentenceType.MIDDLE,

    # 发送音频数据
    await sendAudio(conn, audios)              # → sendAudio() → _do_send_audio()

    # 发送 stop 状态
    if sentenceType == SentenceType.LAST:
        await send_tts_message(conn, "stop", None)
```

async def _do_send_audio(conn, opus_packet, flow_control):
    if conn.conn_from_mqtt_gateway:
        # MQTT 网关模式
        timestamp = int(time.time() * 1000) % (2**32)
        await _send_to_mqtt_gateway(conn, opus_packet, timestamp, sequence)
    else:
        # ★ 标准 WebSocket 模式
        await conn.websocket.send(opus_packet)   # ← 原始 Opus 二进制
```

## 五、线程模型说明

本项目使用**混合线程模型**：

```
主线程 (asyncio event loop)
  │
  ├── WebSocketServer._handle_connection()    async
  ├── ConnectionHandler.handle_connection()   async
  ├── _route_message() → 消息处理              async
  └── 所有 async I/O (websocket.send/recv)
  │
  ├── ThreadPoolExecutor (max_workers=5)
  │     └── conn.chat()  ← LLM 调用在此线程中
  │           ├── self.llm.response()         同步 generator
  │           └── asyncio.run_coroutine_threadsafe() 调度异步任务回主线程
  │
  ├── TTS 后台线程 (tts_text_priority_thread)
  │     └── tts_text_queue 消费 → 分句 → to_tts_stream → opus编码
  │
  └── 音频后台线程 (_audio_play_priority_thread)
        └── tts_audio_queue 消费 → asyncio.run_coroutine_threadsafe(sendAudio)
```
