```python
def asr_text_priority_thread(self, conn: "ConnectionHandler"):
    while not conn.stop_event.is_set():
        try:
            message = conn.asr_audio_queue.get(timeout=1)
            future = asyncio.run_coroutine_threadsafe(
                handleAudioMessage(conn, message),
                conn.loop,
            )
            future.result()
```

```python
async def handle_voice_stop(self, conn, asr_audio_task):
    # 并行执行 ASR 识别 + 声纹识别
    asr_task = self.speech_to_text_wrapper(
        asr_audio_task, conn.session_id, conn.audio_format
    )
    asr_result = await asr_task
    raw_text, _ = asr_result
    # 构造增强文本（含说话人信息）
    enhanced_text = self._build_enhanced_text(raw_text, speaker_name)
    # 调用 startToChat → 进入 LLM 环节
    await startToChat(conn, enhanced_text)
```

### ⑥ startToChat：提交 LLM 聊天任务

**文件**: `xiaozhi-server/core/handle/receiveAudioHandle.py:34-57`（精简）

```python
async def startToChat(conn, text):
    # 意图处理...
    intent_handled = await handle_user_intent(conn, actual_text)
    if intent_handled:
        return

    # 发送 STT 消息给客户端
    await send_stt_message(conn, actual_text)
    conn.client_abort = False

    # 提交 LLM chat 到线程池 —— 这是用户文本进入 LLM 的最终入口
    conn.executor.submit(conn.chat, actual_text)
```

## 结论（插入点建议）

如果需要**在用户文本送入 LLM 之前插入预处理逻辑**（如敏感词过滤、对话改写、多轮摘要等），推荐以下两个插入点：

| 优先级 | 插入位置 | 文件:行号 | 理由 |
|---|---|---|---|
| **★ 首选** | `startToChat()` 函数体内，`actual_text` 赋值后、`conn.executor.submit(conn.chat, ...)` 之前 | `receiveAudioHandle.py` ~第57行 | 此时文本已从 ASR 输出纯文本形态，还未发给 LLM；修改后调用 `conn.chat` 即可 |
| 备选 | `handle_voice_stop()` 内，`enhanced_text` 构造后、`await startToChat()` 之前 | `asr/base.py` ~第174行 | 此时刚拿到 ASR 原始结果，可以联动声纹信息一起处理 |

> **注意**：若需修改发送给客户端的 STT 显示文本，在 `startToChat` 中 `send_stt_message()` 之后修改 `actual_text` 即可，两者可不同步。
