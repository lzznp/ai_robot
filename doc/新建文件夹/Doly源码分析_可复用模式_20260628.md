**引擎循环**（`app_action_seq.c:384-408`）：

```c
static void engine_task(void *arg) {
    for (;;) {
        TickType_t timeout = calc_timeout();          // 计算剩余延时
        BaseType_t got = xQueueReceive(eng.queue, &msg, timeout);
        if (got == pdTRUE) {
            process_msg(&msg);                        // 外部命令
            continue;
        }
        on_delay_expired();                           // 延时到期 → 推进序列
    }
}
```

**步骤推进**（`app_action_seq.c:260-285`）：

```c
static void advance(void) {
    while (eng.seq && eng.step_idx < eng.seq->count) {
        const action_cmd_t *step = &eng.seq->steps[eng.step_idx];

        if (step->type == ACTION_DELAY) {
            start_delay(step->params.delay.duration);  // 延时 → 等待下次 tick
            eng.step_idx++;
            return;
        }

        if (step->type < ACTION_TYPE_MAX && g_handlers[step->type]) {
            g_handlers[step->type](step);               // 调用 Handler
        }
        eng.step_idx++;
    }
    // 所有步骤完成 → 进入复位阶段
    do_reset_tick();
}
```

| 模式 | 文件 | 说明 | 适配方式 |
|---|---|---|---|

### 4.3 与现有架构的兼容性

| 现有组件 | Doly 组件 | 兼容性 |
|---|---|---|
| `EmoteDisplay` (GFX/EAF) | `ui_emoji.c` (LVGL) | **不兼容** — GFX vs LVGL，但可参考表情参数表 |

### 4.4 需要修改才能适配的部分

| Doly 代码 | 需要修改 | 原因 |
|---|---|---|
| `ACT_SERVO(id, angle, dur)` Handler | **替换** | Doly 用 `app_servo_set_target_angle`，需替换为实际舵机驱动 |
| `ACT_MOTOR` Handler | **替换或移除** | Doly 有履带电机，目标机器人不一定有 |
| 表情切换 API `ui_emoji_set_expression()` | **适配** | 需接入现有 `emotion_map`（emote.json → EAF vs LVGL 渲染） |
| 硬件初始化 `dooi_peripherals_init()` | **替换** | 依赖 Doly 特有硬件 |

### 4.5 整合路线图

```
Phase 1 — 直接复用
  ├── action_seq.h 头文件/数据结构
  ├── 序列定义宏 (DEFINE_SEQUENCE + ACT_xxx)
  └── Handler 注册表框架

Phase 2 — 改造适配
  ├── 替换 Handler 实现 (servo/motor/LED → 你的硬件)
  ├── 将 action_cmd_t 解析集成到 MCP 工具
  └── 移植 21 种表情参数表到 LVGL 显示

Phase 3 — 设计融合
  ├── 引入事件驱动状态机 (参考 app_ui_logic)
  ├── 动作序列与 TTS 状态机联动
  └── 自定义 MCP 工具支持实时动作控制
```
