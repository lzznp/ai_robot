### 说明

- `AddTextFont()` — 添加字体
- `AddEmojiData()` — 添加表情动画数据
- `AddIconData()` — 添加图标数据

## 3. emote.json 在 assets 分区中的使用

### 状态：✅ 文件存在

**emote.json 文件位置（共 3 个）：**

| 路径 | 说明 |
|---|---|
| `esp32-firmware/main/boards/esp-box-3/emote.json` | ESP-BOX-3 板卡的表情配置 |
| `esp32-firmware/main/boards/echoear/emote.json` | EchoEar 板卡的表情配置 |
| `esp32-firmware/main/boards/lichuang-dev/emote.json` | 立创开发板的表情配置 |

### 代码引用

#### 运行时固件（C++）— 间接使用

**文件：** `main/assets.cc`

```
第 52 行:  从 SPIFFS 分区挂载 assets
第 110 行: 加载 index.json（不是 emote.json）
第 117 行: 解析 index.json 的 JSON 根节点
第 289-327 行: 遍历 JSON 中的 emoji_collection 数组，通过 GetAssetData() 读取图片资源
```

运行时固件**不直接读取 `emote.json`**。它从 SPIFFS assets 分区中读取 `index.json`，该 `index.json` 的 `emoji_collection` 和 `icon_collection` 字段包含了表情的名称、文件路径、动画参数。

#### 构建脚本（Python）— 直接使用

**文件：** `scripts/spiffs_assets/build.py`

```
第 116-136 行: load_emoji_config(emoji_collection_dir)
                 → 打开目录下的 emote.json，解析为 dict
第 118 行: config_path = os.path.join(emoji_collection_dir, "emote.json")
```

构建脚本在生成 SPIFFS 资产镜像时，会读取板卡目录下的 `emote.json`，将其中的表情映射表嵌入到资产包中，最终写入 SPIFFS 分区供运行时使用。

### 数据流

```
构建时:
  main/boards/<board>/emote.json
  ──→ scripts/spiffs_assets/build.py:load_emoji_config()
  ──→ 生成 SPIFFS 镜像（含 index.json + 图片/动画文件）

运行时:
  SPIFFS 分区（index.json + .eaf / .png / .bin 文件）
  ──→ main/assets.cc:LoadAssetsFromJson()
  ──→ emote_display->AddEmojiData() / AddIconData()
```
