### 2.2 EmoteDisplay::SetEmotion

**文件**: `main/display/emote_display.cc:390-412`

```cpp
void EmoteDisplay::SetEmotion(const char* const emotion)
{
    if (!emotion) {                                         // 行 392: 空指针保护
        ESP_LOGE(TAG, "SetEmotion: emotion is nullptr");
        return;
    }
    ESP_LOGI(TAG, "SetEmotion: %s", emotion);              // 行 397: 日志
    if (!engine_) { return; }                               // 行 398: 引擎存在性检查

    const AssetData emoji_data = GetEmojiData(emotion);     // ★ 行 402: 查表情名称→资产
    bool repeat = emoji_data.loop;                          // 行 403: 是否循环
    int fps = emoji_data.fps > 0 ? emoji_data.fps : 20;    // 行 404: 帧率

    if (std::strcmp(emotion, "idle") == 0 ||                // 行 406-408: idle/neutral强制不循环
        std::strcmp(emotion, "neutral") == 0) {
        repeat = false;
    }

    DisplayLockGuard lock(this);                            // 行 410: 加锁
    engine_->SetEyes(emotion, repeat, fps, this);           // ★ 行 411: 调用 GFX 引擎
}
```

### 2.3 GFX 引擎渲染：EmoteEngine::SetEyes

**文件**: `main/display/emote_display.cc:310-332`

```cpp
void EmoteEngine::SetEyes(const std::string &emoji_name, const bool repeat,
                          const int fps, EmoteDisplay* const display)
{
    if (!engine_handle_) { return; }
    if (!display) { return; }

    const AssetData emoji_data = display->GetEmojiData(emoji_name);  // ★ 查找资产
    if (emoji_data.data) {
        DisplayLockGuard lock(display);
        gfx_anim_set_src(g_obj_anim_eye, emoji_data.data, emoji_data.size);     // ← 加载动画帧
        gfx_anim_set_segment(g_obj_anim_eye, 0, 0xFFFF, fps, repeat);           // ← 设置参数
        gfx_obj_set_visible(g_obj_anim_eye, true);                              // ← 显示
        gfx_anim_start(g_obj_anim_eye);                                          // ← 开始播放
    } else {
        ESP_LOGW(TAG, "SetEyes: No emoji data found for %s", emoji_name.c_str());
    }
}
```

### 2.4 GFX API 说明

| 函数 | 作用 |
|---|---|
| `gfx_anim_set_src(obj, data, size)` | 从内存加载 EAF 动画帧数据到动画对象 |
| `gfx_anim_set_segment(obj, start, end, fps, loop)` | 设置播放区间、帧率、是否循环 |
| `gfx_obj_set_visible(obj, true)` | 显示动画对象 |
| `gfx_anim_start(obj)` | 开始播放动画 |

### 3.2 index.json 结构

`index.json` 是从板卡目录下的 `emote.json` + 图片资源文件，通过 `scripts/spiffs_assets/build.py` 构建 SPIFFS 分区镜像时生成的。

**构建时流程**:
```
main/boards/<board>/emote.json         ← 表情名称→资源文件映射
main/boards/<board>/<anim>.eaf         ← 实际动画文件
  │

        │ load_emoji_config() 读取 emote.json
        │ 生成 SPIFFS 镜像（含 index.json + 资源文件）

```

## 5. 表情切换行为分析

### 5.1 切换流程

当新的表情到来时，`SetEyes` 被重新调用：

```cpp
gfx_anim_set_src(g_obj_anim_eye, new_data, new_size);  // ← 替换动画帧数据
gfx_anim_set_segment(g_obj_anim_eye, 0, 0xFFFF, fps, repeat); // ← 重设参数
gfx_obj_set_visible(g_obj_anim_eye, true);
gfx_anim_start(g_obj_anim_eye);                         // ← 重新开始播放
```

### 5.2 是否有过渡动画

**没有过渡动画**。GFX 引擎直接：
1. 停止当前动画（`gfx_anim_set_src` 会替换）
2. 加载新动画数据
3. 从第 0 帧开始播放

切换是**硬切换**，无淡入淡出或过渡效果。

### 5.3 循环行为

| 表情 | loop | 行为 |
|---|---|---|
| `happy`, `laughing`, `funny`, ... | `true` | 一直循环播放 |
| `idle` | `false`（代码强制） | 播放一次后静止在最后一帧 |
| `neutral` | `false`（代码强制） | 播放一次后静止在最后一帧 |

`idle` 和 `neutral` 的 loop 强制为 false（`emote_display.cc:406-408`），同时 `emote.json` 中配置的 loop 也为 false。

### 5.4 多个表情共享同一个 EAF 文件

查看 `emote.json`:
```
happy, laughing, funny, loving, embarrassed, confident, delicious,
silly, surprised, relaxed → 全部共用 Happy.eaf
```

当服务端下发 `"emotion":"happy"` 和 `"emotion":"laughing"` 时，**固件播放的是同一段动画**，无法区分。

## 6. 关键限制与注意事项

| 限制 | 说明 | 影响 |
|---|---|---|
| **硬切换动画** | 无过渡效果 | 切换瞬间有突兀感 |
| **8 个表情共享 1 个 Happy.eaf** | `funny`, `loving` 等与 `happy` 动画相同 | 不同表情名但显示效果一样 |
| **仅 EmoteDisplay 板卡支持** | 非 EmoteDisplay 板卡只打日志 | 无表情显示 |
| **Kconfig 未包含 lingkong 板卡** | `USE_EMOTE_MESSAGE_STYLE` 依赖列表无 lingkong | 需手动添加 `BOARD_TYPE_LINGKONG_S3_MOC_CAM_1_54TFT` |
