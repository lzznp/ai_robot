## 1. 核心发现：架构差异

### 1.1 硬件架构天差地别

| 维度 | lingkong-s3-moc-cam-1.54tft（参考板） | MOSS 550W |
|------|---------------------------------------|-----------|
| **音频编解码** | ES8311 外置 Codec 芯片（I2C 控制） | 无外置 Codec 芯片 |
| **扬声器** | 通过 ES8311 DAC 输出 | NS4168 I2S 功放直驱 |
| **麦克风** | 通过 ES8311 ADC 输入（标准 I2S） | INMP441 PDM 数字麦克风 |
| **I2S 模式** | 全双工（I2S_NUM_0，同一组 BCLK/WS/DOUT/DIN） | 双单工（I2S_NUM_1 TX + I2S_NUM_0 RX PDM） |
| **MCLK** | 需要 MCLK（GPIO_NUM_42） | 不需要 MCLK（NS4168 和 INMP441 均不需要） |
| **I2C 总线** | 需要 I2C 初始化（GPIO21/14） | 不需要 I2C（除非接 OLED） |

### 1.2 结论：lingkong 参考板的音频代码 => **不可直接复用**

>  **需修改**：lingkong 的 `Es8311AudioCodec` + `CustomAudioCodec` 体系与 MOSS 550W 的硬件完全不兼容。  
>  **正确路径**：参考 **`df-s3-ai-cam`** 或 **`doit-s3-aibox`** 板的 `NoAudioCodecSimplexPdm` 模式。

### 3.2 派生类谱系（关键选择）

```
AudioCodec (基类，抽象)
├── Es8311AudioCodec    ← lingkong 所用（外置 Codec 芯片，全双工 I2S）
├── Es8374AudioCodec    ← 类似，不同芯片型号
├── Es8388AudioCodec
├── Es8389AudioCodec
├── BoxAudioCodec       ← ES8311 + ES7210 双芯片（AEC 回声消除）
├── AdcPdmAudioCodec    ← ADC 麦克风 + PDM 扬声器（esp-hi 专用）
├── DummyAudioCodec     ← 空实现，测试用
└── NoAudioCodec        ← 无外置 Codec 芯片
    ├── NoAudioCodecDuplex       ← 标准 I2S 全双工
    ├── NoAudioCodecSimplex      ← 标准 I2S 双单工（TX+RX 分开）
    └── NoAudioCodecSimplexPdm   ← ★ MOSS 550W 所需：I2S TX + PDM RX
```

### 3.3 `NoAudioCodecSimplexPdm` 完整分析（no_audio_codec.cc:258-359）

这是 **MOSS 550W 最关键的可复用类**。它实现了：
- **扬声器输出**：标准 I2S（I2S_NUM_1，32bit Mono）
- **麦克风输入**：PDM 模式（I2S_NUM_0，16bit Mono）

#### 构造函数（no_audio_codec.cc:263-339）

```cpp
// no_audio_codec.cc:263-339
NoAudioCodecSimplexPdm::NoAudioCodecSimplexPdm(
    int input_sample_rate, int output_sample_rate, 
    gpio_num_t spk_bclk, gpio_num_t spk_ws, gpio_num_t spk_dout, 
    i2s_std_slot_mask_t spk_slot_mask, 
    gpio_num_t mic_sck, gpio_num_t mic_din) 
{
    duplex_ = false;                        // 非全双工
    input_sample_rate_ = input_sample_rate;
    output_sample_rate_ = output_sample_rate;

    // ====== 扬声器通道（标准 I2S TX）=======
    // Step 1: 创建 TX 通道
    i2s_chan_config_t tx_chan_cfg = I2S_CHANNEL_DEFAULT_CONFIG(I2S_NUM_1, I2S_ROLE_MASTER);
    tx_chan_cfg.dma_desc_num = AUDIO_CODEC_DMA_DESC_NUM;    // = 6
    tx_chan_cfg.dma_frame_num = AUDIO_CODEC_DMA_FRAME_NUM;  // = 240
    ESP_ERROR_CHECK(i2s_new_channel(&tx_chan_cfg, &tx_handle_, NULL));

    // Step 2: 配置 I2S 标准模式
    i2s_std_config_t tx_std_cfg = {
        .clk_cfg = {
            .sample_rate_hz = (uint32_t)output_sample_rate_,
            .clk_src = I2S_CLK_SRC_DEFAULT,
            .mclk_multiple = I2S_MCLK_MULTIPLE_256,     // MCLK 未使用，但仍需设置
        },
        .slot_cfg = {
            .data_bit_width = I2S_DATA_BIT_WIDTH_32BIT,  // NS4168 推荐 32bit
            .slot_bit_width = I2S_SLOT_BIT_WIDTH_AUTO,
            .slot_mode = I2S_SLOT_MODE_MONO,
            .slot_mask = spk_slot_mask,                   // 默认为 I2S_STD_SLOT_LEFT
            .ws_width = I2S_DATA_BIT_WIDTH_32BIT,
            .ws_pol = false,
            .bit_shift = true,
        },
        .gpio_cfg = {
            .mclk = I2S_GPIO_UNUSED,                      // ★ NS4168 不需要 MCLK
            .bclk = spk_bclk,                              // NS4168 BCK
            .ws = spk_ws,                                  // NS4168 WS/LRCK
            .dout = spk_dout,                              // NS4168 DIN
            .din = I2S_GPIO_UNUSED,
        },
    };
    ESP_ERROR_CHECK(i2s_channel_init_std_mode(tx_handle_, &tx_std_cfg));

    // ====== 麦克风通道（PDM RX）=======
#if SOC_I2S_SUPPORTS_PDM_RX
    i2s_chan_config_t rx_chan_cfg = I2S_CHANNEL_DEFAULT_CONFIG(I2S_NUM_0, I2S_ROLE_MASTER);
    ESP_ERROR_CHECK(i2s_new_channel(&rx_chan_cfg, NULL, &rx_handle_));
    
    i2s_pdm_rx_config_t pdm_rx_cfg = {
        .clk_cfg = I2S_PDM_RX_CLK_DEFAULT_CONFIG((uint32_t)input_sample_rate_),
        .slot_cfg = I2S_PDM_RX_SLOT_DEFAULT_CONFIG(
            I2S_DATA_BIT_WIDTH_16BIT, I2S_SLOT_MODE_MONO),
        .gpio_cfg = {
            .clk = mic_sck,        // INMP441 PDM CLK
            .din = mic_din,        // INMP441 PDM DATA
            .invert_flags = { .clk_inv = false },
        },
    };
    ESP_ERROR_CHECK(i2s_channel_init_pdm_rx_mode(rx_handle_, &pdm_rx_cfg));
#else
    ESP_LOGE(TAG, "PDM is not supported");  // ESP32-S3 支持 PDM
#endif
}
```

#### Write 方法（继承自 `NoAudioCodec`）（no_audio_codec.cc:217-238）

```cpp
// no_audio_codec.cc:217-238  可在 MOSS 550W 直接复用
int NoAudioCodec::Write(const int16_t* data, int samples) {
    std::lock_guard<std::mutex> lock(data_if_mutex_);
    std::vector<int32_t> buffer(samples);

    // 音量控制：16bit → 32bit + 音量缩放
    int32_t volume_factor = pow(double(output_volume_) / 100.0, 2) * 65536;
    for (int i = 0; i < samples; i++) {
        int64_t temp = int64_t(data[i]) * volume_factor;
        if (temp > INT32_MAX) {
            buffer[i] = INT32_MAX;
        } else if (temp < INT32_MIN) {
            buffer[i] = INT32_MIN;
        } else {
            buffer[i] = static_cast<int32_t>(temp);
        }
    }

    size_t bytes_written;
    ESP_ERROR_CHECK(i2s_channel_write(tx_handle_, buffer.data(), 
        samples * sizeof(int32_t), &bytes_written, portMAX_DELAY));
    return bytes_written / sizeof(int32_t);
}
```

| 标签 | 说明 |
|------|------|
| 可直接复用 | 完全通用，MOSS 550W 可直接使用 |

#### Read 方法（PDM 版本）（no_audio_codec.cc:341-358）

```cpp
// no_audio_codec.cc:341-358  可在 MOSS 550W 直接复用
int NoAudioCodecSimplexPdm::Read(int16_t* dest, int samples) {
    size_t bytes_read;

    // PDM 解调后的数据位宽为 16 位，直接读取
    if (i2s_channel_read(rx_handle_, dest, samples * sizeof(int16_t), 
        &bytes_read, portMAX_DELAY) != ESP_OK) {
        ESP_LOGE(TAG, "Read Failed!");
        return 0;
    }

    samples = bytes_read / sizeof(int16_t);
    // 可选的增益控制
    if (input_gain_ > 0) {
        int gain_factor = (int)input_gain_;
        for (int i = 0; i < samples; i++) {
            int32_t amplified = dest[i] * gain_factor;
            dest[i] = (amplified > INT16_MAX) ? INT16_MAX : 
                      (amplified < -INT16_MAX) ? -INT16_MAX : 
                      (int16_t)amplified;
        }
    }
    return samples;
}
```

| 标签 | 说明 |
|------|------|
| 可直接复用 | PDM 读取逻辑完全通用，INMP441 数据直接读出为 16bit PCM |

## 9. 注意事项与风险

### 9.1 引脚冲突

  **重要**：MOSS 550W 的摄像头引脚（GPIO10-20）与音频引脚存在重叠：

```
CAM_D5 = GPIO_10 ← BCLK  冲突
CAM_D4 = GPIO_11 ← LRCK  冲突
CAM_D2 = GPIO_13 ← PDM CLK 冲突
CAM_D3 = GPIO_12 ← PDM DATA 冲突
```

◀ **建议**：在启用摄像头前，音频引脚端口已通过 `I2S_NUM_0` 和 `I2S_NUM_1` 硬件控制器绑定，不被 GPIO 复用影响。但仍需确认硬件原理图中这些引脚的实际连接。

### 9.2 ESP32-S3 PDM 支持

  ESP32-S3 硬件支持 PDM RX（`SOC_I2S_SUPPORTS_PDM_RX`），但其他芯片（如 ESP32-C3）可能不支持。MOSS 550W 使用 S3 芯片，无此问题。

### 9.3 NS4168 功放使能

  **待确认**：NS4168 是否需要独立的 PA_EN 引脚来控制功放开关。如果需要，需要在 `config.h` 中添加 `AUDIO_SPK_PA_PIN` 宏，并在 `EnableOutput()` 中控制它。

  **参考**：df-s3-ai-cam 使用 `AUDIO_I2S_SPK_GPIO_GAIN`（GPIO41）控制 NS4168 的增益。MOSS 550W 可类似处理。

### 9.4 MCLK 不需要

  **不要连接 MCLK**：NS4168 和 INMP441 都不需要 MCLK 信号。`NoAudioCodecSimplexPdm` 中 TX 配置使用 `mclk = I2S_GPIO_UNUSED`，PDM RX 根本没有 MCLK 参数。

### 9.5 音量控制

  `NoAudioCodec::Write()` 已实现软件音量控制（16bit → 32bit 缩放），无需额外硬件音量控制。
