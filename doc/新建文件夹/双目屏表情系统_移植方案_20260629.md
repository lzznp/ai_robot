# 双目屏 LVGL 表情系统移植方案

**日期**: 2026-06-29
**目标**: 将 Doly (dooirobot) 的 LVGL 表情系统移植到双目屏固件

---

## 1. 现有系统分析

### 1.1 来源系统（Doly — ui_emoji.c）

| 特性 | 详情 |
|---|---|
| 渲染方式 | 纯 LVGL 动画（无图片/无 EAF） |
| 表情数量 | 21 种 |
| 参数维度 | 5 维 `eye_state_t`：宽(w)、高(h)、旋转(angle)、X偏移(x_ofs)、Y偏移(y_ofs) |
| 动画曲线 | `lv_anim_path_overshoot`（Q 弹过冲效果） |
| 自动眨眼 | 每 2.5~6 秒随机眨眼，避开 sleepy/relaxed/shocked/winking |
| 左右同步 | 左眼 0ms 开始，右眼 30ms 延迟错位 |
| API | `ui_emoji_set_expression(const char* name)` — 字符串名称查找 |
| 屏幕数 | 2 屏（左眼/右眼各一屏） |
| 依赖 | LVGL, FreeRTOS semaphore, 双屏管理器 |

### 1.2 目标系统（Waveshare Dual-Eye — display_manager.cc）

| 特性 | 详情 |
|---|---|
| 屏幕数 | 2 屏（各 240×240 GC9A01） |
| LVGL 状态 | **已初始化**（`SpiLcdDisplayExtended` 构造函数中） |
| `DisplayManager::SetEmotion()` | 当前遍历所有显示屏调用 `display->SetEmotion()` |
| **当前实现** | `display->SetEmotion()` → 继承 `Display` 基类 → **仅打日志，`ESP_LOGW`** |
| 渲染层 | `lvgl_port_add_disp()` 已创建，LVGL 可用 |
| 颜色格式 | LV_COLOR_FORMAT_RGB565 |
| PSRAM | 有（8MB/2MB 检测，用于图片缓存） |

### 2.4 新建 ui_emoji_dualeye.cc

**核心修改**：与原始 `ui_emoji.c` 的区别

| 原始 Doly 代码 | 移植后代码 |
|---|---|
| `#include "app_ui.h"` | `#include "ui_emoji_dualeye.h"` |
| 依赖 `screen_manager.screens[DISPLAY_LEFT].root` | 使用传入的 `lv_disp_t*` 创建独立对象 |
| `screen_interface_t emoji_screen_interface` | 不需要，通过 `ui_emoji_init`/`ui_emoji_update` API |
| `lv_timer_handler()` 在 `emoji_update()` 中 | 由原有 LVGL 任务处理 |

**保留**：21 种表情参数表、`lv_anim_path_overshoot` 曲线、自动眨眼逻辑、5 维 `eye_state_t`。

```cpp
// ui_emoji_dualeye.cc 框架（基于 ui_emoji.c 修改）

#include <stdio.h>
#include <string.h>
#include "esp_log.h"
#include "freertos/FreeRTOS.h"
#include "freertos/semphr.h"
#include <lvgl.h>
#include "ui_emoji_dualeye.h"

static const char *TAG = "EmojiDualEye";

/* --- 颜色与基础尺寸 --- */
#define EMOJI_COLOR    lv_color_hex(0x00E5FF)  // 科技青
#define EYE_DEFAULT_W  60
#define EYE_DEFAULT_H  100
#define EYE_RADIUS_MAX 100

/* --- 21 种表情枚举（与 dooirobot 完全一致） --- */
typedef enum {
    EMOJI_NEUTRAL, EMOJI_HAPPY, EMOJI_LAUGHING, EMOJI_FUNNY, EMOJI_SAD,
    EMOJI_ANGRY, EMOJI_CRYING, EMOJI_LOVING, EMOJI_EMBARRASSED, EMOJI_SURPRISED,
    EMOJI_SHOCKED, EMOJI_THINKING, EMOJI_WINKING, EMOJI_COOL, EMOJI_RELAXED,
    EMOJI_DELICIOUS, EMOJI_KISSY, EMOJI_CONFIDENT, EMOJI_SLEEPY, EMOJI_SILLY,
    EMOJI_CONFUSED, EMOJI_MAX
} emoji_type_t;

/* --- 5 维眼状态（与 dooirobot 完全一致） --- */
typedef struct {
    int32_t w;       // 宽度
    int32_t h;       // 高度
    int32_t angle;   // 旋转 (0.1度)
    int32_t x_ofs;   // X轴偏移
    int32_t y_ofs;   // Y轴偏移
} eye_state_t;

typedef struct {
    lv_obj_t *eye_obj;
    eye_state_t current_state;
} eye_widgets_t;

static struct {
    eye_widgets_t left;
    eye_widgets_t right;
    char current_emoji_name[32];
    emoji_type_t target_type;
    bool needs_refresh;
} emoji_ctx = {0};

static SemaphoreHandle_t s_emoji_mutex = NULL;

/* --- 表情名称映射（21 个，与 dooirobot 完全一致） --- */
static const char *emoji_names[] = {
    "neutral", "happy", "laughing", "funny", "sad", "angry", "crying", "loving",
    "embarrassed", "surprised", "shocked", "thinking", "winking", "cool", "relaxed",
    "delicious", "kissy", "confident", "sleepy", "silly", "confused"
};

/* --- 动画回调（与 dooirobot 完全一致） --- */
static void anim_w_cb(void *var, int32_t v) {
    if (v < 6) v = 6;
    lv_obj_set_width((lv_obj_t *)var, v);
    lv_obj_set_style_transform_pivot_x((lv_obj_t *)var, v / 2, 0);
}
static void anim_h_cb(void *var, int32_t v) {
    if (v < 6) v = 6;
    lv_obj_set_height((lv_obj_t *)var, v);
    lv_obj_set_style_transform_pivot_y((lv_obj_t *)var, v / 2, 0);
}
static void anim_angle_cb(void *var, int32_t v) { lv_obj_set_style_transform_rotation((lv_obj_t *)var, v, 0); }
static void anim_x_cb(void *var, int32_t v) { lv_obj_set_style_translate_x((lv_obj_t *)var, v, 0); }
static void anim_y_cb(void *var, int32_t v) { lv_obj_set_style_translate_y((lv_obj_t *)var, v, 0); }

/* --- Q弹动画引擎（与 dooirobot 完全一致） --- */
// anim_eye_to_state() — 直接复制自 ui_emoji.c:71-101
// render_emoji_logic() — 直接复制自 ui_emoji.c:105-200 (21 种表情的 5 维参数)

/* --- 初始化：创建左右眼对象 --- */
void ui_emoji_init(lv_disp_t *disp_left, lv_disp_t *disp_right) {
    s_emoji_mutex = xSemaphoreCreateMutex();

    // 在左显示屏创建左眼
    lv_obj_t *scr_left = lv_disp_get_scr_act(disp_left);
    // 创建眼睛对象...
    create_eye(scr_left, &emoji_ctx.left);
    // 左眼偏移到左侧
    lv_obj_align(emoji_ctx.left.eye_obj, LV_ALIGN_CENTER, -40, 0);

    // 在右显示屏创建右眼
    lv_obj_t *scr_right = lv_disp_get_scr_act(disp_right);
    create_eye(scr_right, &emoji_ctx.right);
    lv_obj_align(emoji_ctx.right.eye_obj, LV_ALIGN_CENTER, 40, 0);

    render_emoji_logic(EMOJI_NEUTRAL);
    ESP_LOGI(TAG, "Dual-eye emoji initialized");
}

/* --- 外部 API（与 dooirobot 完全一致） --- */
void ui_emoji_set_expression(const char *name) {
    // 直接复制 ui_emoji.c:204-218
    if (name == NULL || s_emoji_mutex == NULL) return;
    if (xSemaphoreTake(s_emoji_mutex, pdMS_TO_TICKS(100)) == pdTRUE) {
        strncpy(emoji_ctx.current_emoji_name, name, 31);
        for (int i = 0; i < EMOJI_MAX; i++) {
            if (strcmp(name, emoji_names[i]) == 0) {
                emoji_ctx.target_type = (emoji_type_t)i;
                break;
            }
        }
        emoji_ctx.needs_refresh = true;
        xSemaphoreGive(s_emoji_mutex);
    }
}

/* --- 周期性刷新 --- */
void ui_emoji_update(void) {
    // 处理表情切换请求
    if (emoji_ctx.needs_refresh) { ... render_emoji_logic(type); }
    // 自动眨眼逻辑（复制 ui_emoji.c:288-327）
    ...
}
```

```cpp
// display_manager.cc — 文件顶部新增
#include "ui_emoji_dualeye.h"

// 修改 SetEmotion — 接入 LVGL 表情
void DisplayManager::SetEmotion(const char* emotion) {
    // ★ 调用 LVGL 表情系统（纯软件渲染，不需要遍历显示屏）
    ui_emoji_set_expression(emotion);
    
    // 可选：仍保留对原显示屏的调用（兼容已有的 GIF/图片表情）
    for (auto display : displays_) {
        if (display) display->SetEmotion(emotion);
    }
}

// ★ 新增：LVGL 定时刷新
void DisplayManager::OnLvglTick() {
    ui_emoji_update();
}

// SpiLcdDisplayExtended 构造函数中增加初始化调用
// 在 lvgl_port_init 和 lvgl_port_add_disp 之后
```

## 5. 依赖关系与编译注意事项

### 5.1 依赖检查

| 依赖项 | 双目屏状态 | 说明 |
|---|---|---|
| LVGL | ✅ **已集成** | `SpiLcdDisplayExtended` 中 `lv_init()` 已调用 |
| LVGL 动画 | ✅ **LVGL 内置** | `lv_anim_*` 系列函数可用 |
| FreeRTOS semaphore | ✅ **已可用** | `freertos/semphr.h` |
| `lv_anim_path_overshoot` | ✅ **LVGL 内置** | LVGL v8+ 原生支持 |
| `esp_log.h` | ✅ **已使用** | |
| `string.h` / `stdio.h` | ✅ **标准库** | |

### 5.2 内存估算

| 项目 | 大小 | 说明 |
|---|---|---|
| 眼睛 LVGL 对象 (每屏) | ~200 bytes × 2 | 两个 `lv_obj_create` |
| 动画结构体 (每动画) | ~64 bytes × 5 × 2 | 5 维参数 × 左右眼 |
| 表情映射表 | ~1 KB | `emoji_names` + 常量 |
| 总计 | **< 5 KB** | 非常轻量 |

### 5.3 注意事项

1. **LVGL 刷新频率**：确保 LVGL timer handler 被周期性调用。如果是原有 `SpiLcdDisplayExtended` 自带的 `lvgl_port_init`，它内部已创建 LVGL 定时任务
2. **线程安全**：`ui_emoji_set_expression()` 使用 semaphore 保护，可从任意任务调用
3. **屏幕对齐**：左眼的 `lv_obj_align` 应偏左（`-40, 0`），右眼偏右（`40, 0`），模拟双眼位置
4. **PSRAM 使用**：表情系统不需要图片缓存，PSRAM 影响不大
