#### 调用链路

```
[浏览器] 固件测试.py
   │ POST http://192.168.199.106:8004/api/command
   │ Body: {"device_id": "...", "command": {...}}
   ▼
[backend] core/api/command_api.py :: send_command()
   ├── 解析 JSON
   ├── 校验参数（device_id / command / 格式）
   ├── 从 request.app["device_manager"] 获取 DeviceManager
   ├── 检查设备在线状态（is_online）
   ├── DeviceManager.send(device_id, command)
   │   └── websocket.send(json.dumps(message))
   └── 返回 {"success": True/False, "message": "...", "data": {...}}
```

#### 已知问题

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| API URL 硬编码 | ⚠️ 高 | `http://192.168.199.106:8004` 写死在页面代码中 |
| 仅支持原始 JSON | 🔵 中 | 用户需手动构造 JSON 指令，没有预设指令模板 |
| 日志无持久化 | 🔵 低 | 页面刷新后日志丢失（仅 session_state 内存） |
| 无设备选择下拉 | 🔵 低 | 需要手动复制 device_id，无法从在线设备列表中选择 |
| 无 HTTP Basic Auth | 🔵 低 | API 端口 8004 无认证 |

## 3. 服务层分析

### command_service.py（✅ 完整实现）

**用途**：封装 `CommandSender`，提供同步调用包装（适配 Streamlit 同步环境）。

```python
class CommandService:
    def __init__(self, command_sender: CommandSender)

    def send_command_sync(self, device_id, command_type, params) -> Dict:
        """同步下发指令（Streamlit 中调用）"""
        loop = asyncio.get_event_loop()
        if loop.is_running():
            # 使用 run_coroutine_threadsafe
            future = asyncio.run_coroutine_threadsafe(...)
            return future.result(timeout=10)
        else:
            return loop.run_until_complete(...)
```

- 与 `core/command_sender.py` 直接耦合
- 处理了 Streamlit 同步环境下调用 async 代码的三种场景（有loop/无loop/RuntimeError）
- 超时设置：10 秒

## 8. 页面与后端 API 调用关系

```
┌──────────────────────────────────────────────────────────┐
│                   后端服务器 (:8004)                       │
│                                                          │
│  app.py (aiohttp)                                        │
│  ┌──────────────────────────────────────────────┐        │
│  │  POST /api/command  → command_api.send_command │        │
│  │  GET  /api/devices  → command_api.get_devices  │        │
│  └───────┬──────────────────────────┬────────────┘        │
│          │                          │                     │
│          ▼                          ▼                     │
│  DeviceManager.send()       DeviceManager.get_online()    │
│          │                                                │
│          ▼                                                │
│  WebSocket → 固件设备                                      │
└──────────────────────────────────────────────────────────┘
           ▲                           ▲
           │ HTTP                      │ HTTP
           │                           │
┌──────────┴───────────┐   ┌──────────┴───────────┐
│   固件测试页面         │   │   (待实现) 设备管理页面  │
│   requests.post()     │   │   requests.get()      │
│   command_service.py  │   │   device_service.py   │
│   ❌ api_client.py     │   │   ❌ api_client.py     │
└──────────────────────┘   └──────────────────────┘
           │
           ▼
   command_service.py / device_service.py
        ↓ 直接 import (仅限同进程)
   core/command_sender.py / core/device_manager.py
```

### 两种调用模式

| 模式 | 说明 | 使用场景 |
|------|------|----------|
| **HTTP API** | 页面通过 `requests.post` 调用 `:8004/api/command` | 固件测试页面（当前实现） |
| **直接调用** | 页面 import `core/command_sender` + `core/device_manager` | 未来如果 Streamlit 与后端同进程运行 |
